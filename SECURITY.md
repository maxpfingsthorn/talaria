# Security

Talaria runs with access to your Hermes data, its backups and your Telegram bot token,
so security reports are welcome.

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/maxpfingsthorn/talaria/security/advisories/new),
not in a public issue. I will reply as soon as I can; this is a one-person project.

Only the latest release is supported. Update with `talaria self-update <tag>`.
